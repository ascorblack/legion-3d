# Legion 3D — город «Легиона» от первого лица

> Описание для поля «Description» в кабинете Chrome Web Store — **только** файл `store/description-ru.txt` (обычный текст: магазин не понимает Markdown). Этот файл — заметки для заполнения кабинета, целиком его не вставлять.

**Краткое описание (≤132):** Неофициальный 3D-режим для игры «Легион»: гуляй по городу, заходи в лавки и шахту, встречай игроков.

## Полное описание

Legion 3D превращает сайт игры «Легион» (play.multidonate.ru) в настоящую 3D-игру. Гуляй по ночной ярмарке от первого или третьего лица — вокруг живые игроки в своих обликах, а их сообщения из чата всплывают над головами.

Что умеет:
• 3D-город по карте сайта: кузня, шатёр, ворота, башня звездочёта, лестницы, канал и мосты
• Первое лицо с лапами и оружием в руках, третье лицо за плечом, настоящие прыжки
• 3D-лавки: ходишь между полками, наводишь прицел — подсвечивается ровно тот товар, который купишь, с карточкой и подтверждением
• 3D-шахта: подходишь к камню и копаешь киркой, скупщик, снабженец, поручения, чат шахты
• Снаряжение с облётом камеры вокруг героя, сумка, характеристики, журнал, карта с «Идти сюда»
• Панель похода: что происходит и что писать в чат
• Звуки ночной ярмарки, шагов, дверей и покупок (тихо по умолчанию)
• Фоторежим (F9) и праздничное оформление (Хэллоуин)
• «Драки с котиками» — смешные удары и падения, видны только тебе
• Подстраивается под слабые видеокарты; F8 — вернуться к обычному сайту

Управление: WASD — идти, Shift — бежать, Space — прыжок, мышь — осмотр, V — камера, E — действие, Tab — меню, M — карта, Enter — чат, F9 — фоторежим, F8 — классический сайт.

Как начать: открой страницу канала https://play.multidonate.ru/c/<канал>/ и войди через Twitch — 3D запустится само.

Важно: это неофициальный фанатский проект, не связанный с авторами «Легиона» и MultiDonate. Расширение работает только на страницах каналов игры, не собирает данные и не использует аналитику. Единственный запрос в сеть, кроме самой игры, — установка из GitHub раз в 12 часов читает номер последней версии на api.github.com (без cookies и без данных о вас); в магазинной версии его нет, отключается в настройках. Все игровые действия идут через обычный клиент сайта. Исходный код: https://github.com/ascorblack/legion-3d

## Поля кабинета
- Категория: Развлечения (Fun). Язык: русский.
- Единственная цель (Single purpose): добавить к сайту игры «Легион» (play.multidonate.ru) необязательный 3D-режим с игровым интерфейсом.
- Обоснование доступа к хосту (Host permission justification): https://play.multidonate.ru/c/* — только на этих страницах открыт игровой «Город». Два скрипта расширения рисуют 3D-сцену и читают данные текущей страницы, чтобы синхронизировать 3D с игрой. Другие сайты не затрагиваются.
- Обоснование host permission для GitHub API (https://api.github.com/repos/ascorblack/legion-3d/releases/latest): анонимный GET без cookies раз в 12 часов (и при запуске браузера), только чтобы узнать номер последней версии и подсказать об обновлении тем, кто установил расширение из GitHub-архива; в магазинной установке (update_url задан магазином) запрос не выполняется. Ничего не скачивается и не исполняется. Permission storage: время последней проверки.
- Удалённый код (Remote code): Нет — весь исполняемый код и графика поставляются в пакете.
- Сбор данных (Data usage): ничего не отмечать. Подтвердить три пункта: не продаю данные; не использую их вне единственной цели; не использую для кредитоспособности.
