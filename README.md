# Legion 3D

**[⬇ Установить из Chrome Web Store](https://chromewebstore.google.com/detail/chlcndeaohnmjoeoppfdfchmfkllkemk)** — ставится в один клик и обновляется сам (Chrome, Edge, Яндекс Браузер, Opera).
> ⏳ Каждую новую версию магазин сначала проверяет, поэтому обновления в Chrome Web Store появляются с задержкой — обычно от 4 до 24 часов после релиза на GitHub. Нужно сразу — поставь архив со [страницы релизов](https://github.com/ascorblack/legion-3d/releases/latest).
Firefox и ручная установка — на [странице релизов](https://github.com/ascorblack/legion-3d/releases/latest).

**Неофициальное** расширение для Chrome и Firefox, которое превращает сайт игры «Легион»
([play.multidonate.ru](https://play.multidonate.ru)) в 3D-игру: гуляй по городу от первого или третьего лица,
смотри на других игроков в 3D, читай их сообщения над головами, переодевайся в игровом меню и заходи в лавки,
не выходя из мира.

> Проект не связан с авторами «Легиона» и MultiDonate. Расширение работает поверх сайта: всё, что видит
> и отправляет игра, идёт через тот же клиент сайта, что и в обычном «Городе».

## Возможности

- **3D-город** строится по той же карте, что и 2D-«Город»: улицы, лестницы, канал с мостами, все здания
  смоделированы в 3D (кузня, шатёр, ворота, башня звездочёта, ратуша, вход в шахту…). Новые здания с сайта
  появляются автоматически — обычным домом с вывеской.
- **Первое лицо** с лапами и оружием в руке (удар — ЛКМ, щит — ПКМ) и **третье лицо** за плечом, как в GTA (`V`).
- **Настоящие прыжки** (`Space`): перепрыгнуть скамейку или забор, запрыгнуть на ящик, спрыгнуть с уступа.
- **Другие игроки** в 3D — со своим обликом и снаряжением, двигаются так же, как в 2D-городе.
- **Чат города** — тот же, что на сайте (все вкладки, личные, модерация), а сообщения всплывают над головами.
- **3D-магазины**: заходишь внутрь, ходишь между полками и выбираешь товар прицелом — подсвечивается ровно
  тот предмет, который купится, карточка с характеристиками и подтверждение покупки.
- **3D-шахта**: пещера по настоящей раскладке этажа, копаешь камни киркой, скупщик и снабженец. 12 пластов глубины,
  оценки у камней (≈ сколько осталось, кто копает, твоя доля), очередь камней (`Shift+E`), «Пока тебя не было»,
  поручение недели и дневной лимит.
- **Сигналы шахты**: вкладка браузера показывает «⛏ 12 мин» → «✅ Камень выкопан», тихий звон даже в фоне,
  по желанию — уведомление; в городе значок «⛏ этаж 25 · ≈ 12 мин», `U` — обратно в шахту.
- **Остальные здания** (тренер, доска, ратуша, аукцион, склад, ворота, заточка) — 3D-сцена с NPC и родной
  панелью сайта поверх.
- **Игровые меню**: снаряжение, сумка, характеристики, журнал, навыки, достижения, рейтинг, новости, карта
  (вид сверху, игроки, «Идти сюда»). В снаряжении камера облетает героя — видно, как сидит обновка.
- **Поход**: пока он идёт, на экране панель с фазой, таймером (с задержкой стрима) и тем, что писать в чат,
  а `Q` показывает его в 3D — бой, карта, загадки, события Изнанки, гоблинская ярмарка, босс.
- **Путешествие** (`L`): сменить город или канал прямо из 3D.
- **Стиль канала** подхватывается на лету: котики, «Чертики» (бесята с рожками и хвостами, «Чёртов привал»), Легион.
- **Режим отладки** (`F10`, включается в настройках): тестовое измерение, сцены похода, оверлеи — см. ниже.
- **Адаптивное качество**: работает и на слабых видеокартах — разрешение и детализация подстраиваются сами.
- `F8` в любой момент возвращает классический сайт.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | ходьба, `Shift` — бег, `Space` — прыжок |
| мышь | осмотр (клик по экрану захватывает курсор) |
| `V` | первое ⇄ третье лицо, колесо — отдалить камеру |
| `E` | войти, купить, копать, поговорить — то, что подсвечено (мышью мир не трогаем: ЛКМ — удар, ПКМ — щит) |
| `F` | осмотреть (карточка предмета) |
| ПКМ | поднять щит |
| `Tab` | меню персонажа |
| `C` `I` `P` `K` `Y` `J` `O` | снаряжение · сумка · характеристики · навыки · достижения · журнал · облик |
| `M` `R` `N` | карта · рейтинг · новости |
| `Enter` / `T` | чат |
| `L` | путешествие: города и каналы (в шахте — журнал шахты) |
| `Q` / `U` | поход в 3D (пока идёт) / вернуться в шахту |
| `Esc` | закрыть окно / выйти из помещения / пауза |
| `F2` / `F3` | спрятать интерфейс / счётчик FPS |
| `F8` | классический сайт ⇄ 3D |
| `F10` | панель отладки (если включён режим отладки) |

Полная раскладка: [docs/GAME-DESIGN.md](docs/GAME-DESIGN.md).

## Режим отладки

Для тестеров и любопытных: **Настройки → Отладка → Режим отладки** (по умолчанию выключен — пока выключен, ничего из
этого не загружается и не видно). Включил — `F10` или пункт **«🐞 Отладка»** в меню `Esc` открывает панель:

| Вкладка | Что там |
|---|---|
| Измерение | **Тестовое измерение** — отдельный мир-витрина, куда переносишься одной кнопкой: все модели предметов на стендах (прицел + `E`/`F` — карточка), все облики на котиках-манекенах, все враги походов (с `hw_*` и Тыквенным големом), жители (продавцы, мастера, гости Хэллоуина), порталы в 3D-лавки, интерьеры, шахту, лагерь «Перепутье», город округа и Ярмарку (демо-версии), тотемы праздников; время суток (ночь, рассвет, день, вечер, ползунок). Выход — туда же, где стоял (кнопка, `Esc` → «Вернуться в город») |
| Поход | **Сцены похода** в 3D на демо-данных: бой, карта и сбор, ловушки, события и лавка, босс (тишина, финт, площадки, слова, прислужники), головоломки, праздничное — и «Авто-проигрывание» всего похода с таймлайном, паузой и ×1/×2/×4 |
| Мир | свободная камера (noclip), качество q0–q3, праздник в городе (Хэллоуин, Новый год, лето, 1 апреля), Ночь Тыквенной Луны (вид / портал), демо-боты с облачками |
| Оверлеи | счётчик производительности с графиком (fps, мс, вызовы, треугольники, качество, память), сетка проходимости и хитбоксы, каркас |
| Сайт | проверка контракта сайта (зелёный / красный список), что не поддерживается (drift), версии скриптов сайта и **«Скопировать отчёт»** для сообщения о баге — без логина, ника и cookies |
| Шина | что сайт присылает расширению: типы событий, счётчики, последнее (ники скрыты) |

Всё это только у тебя в браузере: во время отладки на сайт ничего не отправляется (герой на сайте стоит, где стоял),
покупки и прочие действия в демо-лавках не уходят, моки похода не попадают ни в окно похода сайта, ни на сервер.
Офлайн: `dist-dev/game.html?debug=1`; проверка — `node dev/debug-check.mjs`, скриншоты — `node dev/debug-shots.mjs`.

## Установка

1. Скачай `legion-3d-<версия>.zip` со страницы [последнего релиза](https://github.com/ascorblack/legion-3d/releases/latest)
   и распакуй в любую папку (папку потом не удаляй).
2. Открой `chrome://extensions`, включи «Режим разработчика» (справа вверху).
3. «Загрузить распакованное расширение» → выбери распакованную папку (где лежит `manifest.json`).
4. Открой страницу канала `https://play.multidonate.ru/c/<канал>/` и войди через Twitch. Игра запустится сама,
   или нажми «Играть в 3D» / `F8`.

Работает в Chrome 111+ и других браузерах на Chromium. Обновление — распаковать новый архив поверх старого
и нажать «Обновить» у расширения.

### Firefox 128+

Скачай **`legion-3d-<версия>-firefox.xpi`** со [страницы релизов](https://github.com/ascorblack/legion-3d/releases/latest),
открой его в Firefox (или перетащи в окно браузера) и нажми «Добавить». Файл подписан Mozilla, поэтому расширение
остаётся после перезапуска браузера. Обновление — открыть `.xpi` новой версии.

В Firefox нет Keyboard Lock: полноэкранный режим доступен, но защита Ctrl+W работает только через подтверждение закрытия.

Сборка из исходников: `npm run build:firefox -- --prod` → `dist-firefox/`. Неподписанную сборку Firefox загружает
только временно (`about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение»). Релизы подписывает CI
через AMO (канал unlisted) — нужны секреты репозитория `AMO_JWT_ISSUER` и `AMO_JWT_SECRET`.

### Из исходников

```bash
npm ci
npm run build          # dist/ — распакованное расширение
```

Релиз собирается сам: тег `vX.Y.Z` (версия как в `public/manifest.json`) → GitHub Actions прогоняет тесты,
собирает и прикладывает zip к релизу.

## Разработка

```bash
npm run dev            # пересборка при изменениях
npm run typecheck
npm test               # vitest
npm run drift          # что нового на сайте после его обновления (см. docs/EXTENDING.md)
node scripts/shot.mjs dist-dev/world.html shot.png   # скриншот демо-страницы в headless Chromium
```

Каждый модуль можно смотреть отдельно на своей демо-странице `dist-dev/<module>.html` (без сайта, на фикстурах).
Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Как устроен сайт: [docs/SITE-NOTES.md](docs/SITE-NOTES.md).

| Папка | Что внутри |
|---|---|
| `src/bridge` | скрипт на `document_start`: копирует живые события сайта (SSE) в шину |
| `src/net`, `src/store` | адаптер сайта: вход, город, игроки, чат, действия героя |
| `src/engine` | рендерер, игровой цикл, адаптивное качество, ввод, камеры, движение героя |
| `src/world` | 3D-город из карты сайта |
| `src/avatar` | процедурные персонажи, руки от первого лица, ники и облачка чата |
| `src/ui` | HUD и игровые меню (Shadow DOM) |
| `src/quest` | панель похода |
| `src/core`, `src/features` | реестры (здания, комнаты, модели предметов, меню, клавиши), фичи, прицел и взаимодействие, вход в помещения |
| `src/rooms` | 3D-магазины, сцены зданий с панелью сайта, 3D-шахта |
| `src/content` | точка входа: загрузка, порядок кадра |
| `scripts/drift.mjs` | сравнение свежего сайта с тем, что поддерживает расширение |
| `scripts/video` | покадровая запись обзорного видео (60 fps) |

Как добавить здание, комнату, предмет, вкладку меню или механику — [docs/EXTENDING.md](docs/EXTENDING.md).

## Приватность

Расширение работает только на `play.multidonate.ru/c/*`, ничего не отправляет третьим сторонам и не хранит ничего,
кроме настроек в `localStorage`. Единственное исключение — установка из GitHub (zip/xpi): раз в 12 часов она читает номер
последней версии с `api.github.com/repos/ascorblack/legion-3d/releases/latest` (анонимно, без данных о вас;
выключается в Настройки → Прочее). Установки из магазинов этого не делают. Нужны разрешения `storage` и доступ к этому одному адресу.
Подробно: [Политика конфиденциальности](docs/PRIVACY.md).
