Legion 3D — неофициальное расширение для Firefox 140+

КАК УСТАНОВИТЬ
1. Скачай файл legion-3d-<версия>-firefox.xpi со страницы релиза:
   https://github.com/ascorblack/legion-3d/releases/latest
2. Открой его в Firefox (или перетащи в окно браузера) и нажми «Добавить».
   Расширение подписано Mozilla и остаётся после перезапуска браузера.
3. Открой или обнови страницу канала https://play.multidonate.ru/c/ИМЯ_КАНАЛА/ и войди через Twitch.
   Игра запустится сама. Кнопка «Играть в 3D» или клавиша F8 переключает 3D и обычный сайт.

КАК ОБНОВИТЬ
Скачай и открой .xpi новой версии — Firefox заменит старую.

СБОРКА ИЗ ИСХОДНИКОВ (для разработчиков)
Неподписанную сборку из этой папки можно загрузить только временно:
about:debugging#/runtime/this-firefox → «Загрузить временное дополнение» → manifest.json.
После закрытия Firefox её придётся загрузить снова.

ЕСЛИ 3D НЕ ЗАПУСКАЕТСЯ
Проверь аппаратное ускорение: Настройки Firefox → Основные → Производительность.
После изменения настроек перезапусти браузер.

В Firefox нет Keyboard Lock: полноэкранный режим доступен, но Ctrl+W не блокируется,
остаётся подтверждение закрытия вкладки (после первого действия в игре).

Исходный код: https://github.com/ascorblack/legion-3d
