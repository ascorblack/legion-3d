# Конфиденциальность Legion 3D / Privacy Policy

## Русский

Legion 3D — неофициальное расширение для игры «Легион». Расширение не собирает персональные данные и не передаёт данные разработчику или третьим лицам. Нет аналитики, трекеров, телеметрии и серверов расширения.

Настройки интерфейса, камеры, звука и показ карточки обновлений хранятся **только локально** в `localStorage` страницы игры (`play.multidonate.ru`). Удалить их можно через очистку данных сайта. Расширение работает поверх открытого сайта: игровые запросы и чат обслуживаются самим клиентом игры и серверами игры, согласно политике сайта; расширение не пересылает их себе. Проверка обновлений (только для установки из GitHub — zip для Chrome или .xpi для Firefox; в установках из магазинов её нет, они обновляются через магазин): фоновый скрипт расширения не чаще одного раза в 12 часов и при запуске браузера делает один анонимный GET-запрос `https://api.github.com/repos/ascorblack/legion-3d/releases/latest` (без cookies и без данных о вас; GitHub, как любой сервер, видит IP-адрес запроса), читает из ответа только номер и ссылку последней версии и, если она новее, показывает уведомление со ссылкой на страницу релиза. Ничего не скачивается и не исполняется; время последней проверки и найденный номер версии хранятся в `chrome.storage.local`. Отключается в Настройки → Прочее → «Проверять обновления (GitHub)». Расширение запрашивает разрешение `storage` и доступ к одному адресу GitHub API. Ссылка «Сообщить об ошибке» открывает GitHub; при её нажатии в форму передаются только версия расширения, название GPU renderer, FPS и уровень качества — без никнеймов, чата, cookies и адреса страницы. Перед публикацией отчёта проверьте его содержание.

Вопросы по политике: [GitHub Issues](https://github.com/ascorblack/legion-3d/issues).

## English

Legion 3D is an unofficial extension for the Legion game. The extension does not collect personal data or transmit it to its developer or third parties. It has no analytics, trackers, telemetry, or extension-operated servers.

Camera, interface, sound and update-card preferences are stored **only locally** in the game page's `localStorage` (`play.multidonate.ru`). Clear the site's data to delete them. The extension runs on the game website; game requests and chat are handled by the website's own client and servers under the site's policy, and are not forwarded to the extension developer. Update check (GitHub installs only — the Chrome zip or the Firefox .xpi; store installs update through their store and never check): at most once every 12 hours and when the browser starts, the extension's background script makes one anonymous GET request to `https://api.github.com/repos/ascorblack/legion-3d/releases/latest` — no cookies and nothing about you is sent (GitHub, like any server, sees the requesting IP address). It reads only the version number and release link from the reply and, if the version is newer, shows a notice linking to the release page. Nothing is downloaded or executed; the time of the last check and the version found are kept in `chrome.storage.local`. Switch it off in Settings → Прочее → “Проверять обновления (GitHub)”. The extension requests the `storage` permission and access to that single GitHub API address. Clicking “Report a bug” opens GitHub with only extension version, GPU renderer name, FPS and quality level prefilled—no player names, chat, cookies or page address. Review your report before submitting it.

Privacy questions: [GitHub Issues](https://github.com/ascorblack/legion-3d/issues).
